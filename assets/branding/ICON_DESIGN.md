# 煜莹 · 应用图标

应用名称：煜莹。Android 和 iOS 桌面图标均使用用户提供的黑色玫瑰及手写字 Logo，与首页保持一致。

原始文件 `logo.jpg` 保留原始字节。图标只进行尺寸转换和白色留边，不重绘、裁切或改色。`app-icon.png` 为不透明 RGB 的 1024×1024 主图；iOS 按 AppIcon 目录尺寸导出；Android 含五档密度的传统图标和自适应图标。

传统及 iOS 图标将原图居中置于 92% 宽度。Android 自适应图标使用白底、108 dp 前景画布和 64 dp 居中的原图，将玫瑰和底部手写延伸笔划保留在 66 dp 圆形安全区内，避免系统圆形裁切遮住图案。
