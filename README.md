# fingertip · 煜莹 v0.19.1

版本 `0.19.1+32`。首页有“美甲”和“美妆”两个入口。美妆打开实时试妆，也可以从相册选图进入照片编辑。安卓实时取景期间保持亮屏，系统短暂中断相机后，回到试妆页会重新接上取景。

照片甲缘会局部复查图案间断和亮面反光。两个局部方向都确认相邻甲面时，可以分开原来连在一起的轮廓。新增或仍有不确定性的区域可在甲缘确认中检查。

照片试戴会复查有重复指纹纹路的疑似指腹，以及遮挡处的小甲面和近灰度照片中的深色甲面。候选仍需独立模型结果支持。已有蒙版会根据照片中清楚的甲油或亮度边界做有限修边，补齐相连的甲尖并裁掉边外皮肤，保留原有手工修边入口。实时计数保持原有轻量识别路径。

美甲照片识别在全图之后使用重叠局部取景和可用的指尖位置复查。新增甲面需要多个局部结果支持，已选中轮廓内的重复片段会被合并过滤。跨方向缺乏支持的可疑甲面会被复核。存在多片相近强色的甲面时，可用一致颜色定位复查窗口，再由模型确认。自动轮廓在照片坐标内消除细小台阶并重建窄边缘。相机实时计数仍使用原有轻量路径，所有阶段都在设备上运行。

在照片下方点「＋」复制当前方案，可连续新增并横滑切换。方案可重命名、删除和撤销。每套方案分别记录每指款式、薄厚、光泽和灯光，共用照片、甲缘和查看角度。方案在当前照片的编辑会话内保留，保存和导出使用当前方案。

「款式」「效果」「甲缘」各有独立工具区。竖屏把工具放在照片下方，横屏放在右侧。切换方案、选款及调节效果时都在原位置预览。

点款式旁的爱心可收藏内置款和 DIY 款，分类条首位可查看。「收藏」仅在应用本地文档中写入款式 ID，重开仍可使用。原照片与 DIY 原图保留在各自原有流程。

试戴照片直接显示上色效果。需要检查甲缘时，在「甲缘」中点选甲面并选「修边贴合」。可用「放大修边」拖动控制点，整片漏识别时可用「补选」。

相机默认显示原肤。内置 34 套妆容，含白开水妆、淡颜清冷、千金妆、港风红唇、墨兰国风、金箔暖宴、粉晶微闪等。眼影、腮红和口红可按色系筛选，并可单独选用细闪唇釉。配色参考了国内小红书样本和当季节日系列。[千瓜小红书样本报告](https://www.qian-gua.com/information/detail/3346) · [CHANEL 2026 节日妆](https://www.chanel.com/us/fragrance-beauty/holiday-gift-ideas/holiday-makeup-look/) · [Dior 2026 节日妆](https://www.dior.com/en_us/beauty/cinnamon-glaze-makeup-collection.html)

整妆浓淡和单项薄厚都能即时调整，浏览分类会保留当前妆效。可一键对比原肤。前后摄可切换、取景可翻转，点按画面可对焦。拍照把当前妆效带到照片编辑，支持继续调整控制点、对比、保存和分享。

Android 在本机使用 CameraX 和 MediaPipe，iOS 在本机使用 AVFoundation 和 Vision。取景和点位按实际视频帧比例对齐。轮廓与眉部共享头部运动响应，眼和唇另外跟随表情，点位过时、丢脸或多人入镜时暂时隐藏妆效。用本机观测到的少量脸颊颜色对所选妆色做有界亮度调整，取样不可靠时用款式原色。眼影和腮红随脸部方向调整，唇妆排除张嘴区域，水光、缎光和镜面光沿下唇方向。照片和取景共用妆效绘制，照片编辑另提供开眼角微调。优先支持单人正脸与小幅转头，遮挡和急转可能影响贴合。

妆效交互参考了[美图魔镜单品试妆](https://mirror.meitu.com/feature_tech?lang=zh)的分层和薄厚调节。妆色透明度和肤色融合参考了[实时试妆研究](https://openaccess.thecvf.com/content/WACV2026/html/Chau_Towards_High-Fidelity_Identity-Preserving_Real-Time_Makeup_Transfer_Decoupling_Style_Generation_WACV_2026_paper.html)。本应用使用本地五官点位和轻量颜色叠加。所有脸部处理在设备上完成。

以下延续 v0.6.7 的品牌更新：

- 应用名称改为“煜莹”；Android/iOS 桌面图标使用用户此前提供的首页玫瑰 Logo，保留原图白底和图案，适配各平台尺寸与裁切安全区。首页 Logo 不变。
- 保留原应用标识，支持覆盖安装并保留照片、DIY 作品与设置。

以下延续 v0.6.6 的图层修复：

- 修复 DIY 图层跨类型上移/下移后遮挡关系不变：图片、素材与手绘现在严格按图层列表顺序合成，列表越靠上显示越靠前，预览、保存 PNG 和重开设计使用同一规则。
- 橡皮仍仅影响位于其下方的笔迹，不擦底色、图片、素材或其上方后画的笔迹。连续笔迹在隔离画布内合成，再应用后续橡皮，避免为了排序而破坏橡皮范围。
- 最顶层“上移”和最底层“下移”按钮置灰，提示同步更新；排序、点选、撤销重做和保存重载共同验证。已有保存款式可打开编辑、调整图层后重新保存以更新试戴贴图；不会批量改写旧作品。

以下延续 v0.6.5 的材质改进：

- 闪粉从固定圆点图案改为甲面上固定的多尺度片状颗粒，颗粒轮廓和取向随款式固定；切换灯光时改变各颗粒的反光强弱，保留有色底和暗部，减少整片白雾感。
- 猫眼保留款式设定的磁纹主轴，按灯光方向改变光带偏移、强度和显现区域，叠加细磁粉与柔和晕光；灯光不会被当作磁铁去旋转整个图案。
- 两种材质的本体反射与封层高光分别处理，降低普通圆形高光在闪粉、猫眼上的覆盖强度。光泽调低后材质仍保留颗粒或磁粉反射，不把它们变成纯色。
- 缩略图、试戴预览和导出共用同一材质实现。效果仍为固定观察方向下的二维近似，没有读取真实灯光、重建三维甲面或模拟真实磁场；也没有新增闪光灯/强度控制。

以下延续 v0.6.4 的甲缘改进：

- 照片识别改为整图定位后逐片局部精识别：以已有甲面为中心准备约 3 倍甲面尺寸的正方形上下文，保留越界边缘复制，使用同一个内置模型复查，不增加在线服务或新检测数量。相机实时计数仍使用原有轻量整图路径。
- 只允许在原甲面的窄边界带内修正，保留内部核心；局部候选需通过重叠、面积比、中心漂移和置信度检查，不能匹配时保留原区域。保留甲面身份、中心和旋转角度，实际覆盖未超框时不改宽高，避免改变花纹比例。
- 照片的精细轮廓从原始概率等值线生成，按真实局部模型像素间距做有界简化和保角平滑，再输出 `128×192` 几何抗锯齿蒙版；不靠大范围羽化、凸包或统一椭圆模板消除毛边。
- 本例真实标注对照中，溢涂像素 `2432→1102`，漏涂 `660→635`，平均边界误差 `2.047→1.139` 像素。小指改善但仍有侧面漏边；部分其他指甲的漏涂增加，不能认为每片或每张照片均已自动精确贴合。该图已用于调参，数据不是独立识别率评测。

以下延续 v0.6.3 的功能：

- 首页底部显示从当前安装包读取的版本号，避免首页文字与实际安装版本脱节。

## 美甲功能

- 美甲使用后置相机自由拍摄，或从系统相册选择照片；美妆的前后摄选择见本版流程说明。
- 相机预览点按对焦和测光，显示对焦位置；试戴照片支持双指缩放旋转、平移和复位，调整视图不改变导出方向。
- 拍照预览显示甲面标记和视窗内计数；拍照后再次识别，预览数量与照片结果可能有差异。
- 照片识别时，Android 使用内置 MediaPipe 模型、iOS 使用系统 Vision 获取可选手部关键点；两端共用内置 ONNX 指甲分割模型。预览只运行甲面分割。
- 提供 240 款内置样式、18 类风格和 41 种图案及材质，通过分类条和样片条直接试戴。另有“我的DIY”保存自己的图片和手绘设计。
- 支持导入图片、82 个装饰素材、底色、手绘、仅擦除笔迹的橡皮、图层、锁位置、缩放旋转、撤销重做，以及 DIY 新建、编辑和删除。
- 款式下方可拖动“薄涂—厚涂”实时改变覆盖。默认在款式原配方位置，薄涂多透出原甲，厚涂模拟叠涂。支持整手或单指，和光泽分别设置，可撤销，按预览效果保存或导出。
- 支持甲面位置、宽度、长度、角度调整、删除、局部补选、八点修边、蒙版扩缩、羽化和撤销。
- 支持按住查看原图、调整光泽、保存 PNG 到 App 本地文件，并通过系统分享导出。
- 支持改变模拟灯光方向观察高光变化，并按当前灯光方向导出。

“补选”把点击位置作为明确种子，在局部裁剪图中重跑分割；只有候选蒙版实际包含该点才接受为局部贴合。找不到这样的候选时提供**可编辑的手动轮廓**，不会把别处的指甲强行移来，也不会冒充模型识别成功。用户可调整位置和方向、拖动八个轮廓控制点，再调扩缩及羽化；App 不会因结果为空而自动套用五片模板。

这些是由本地着色器绘制的 **程序化示意材质**，不是实物甲片照片、品牌色卡或真实光学测量。缩略图使用中性的示意甲片背景，实际试戴还会受原照片底色和光照影响。闪粉和猫眼会随应用内模拟灯光方向变化，金属仍为程序化反射近似；它们不会感知真实光线或随真实手机/手指姿态产生 AR 光学变化。图案覆盖在已有甲面范围内，不会自动改变甲长、甲型或修复遮挡。

## DIY 工作室与本地保存（v0.6）

从编辑页点击“DIY新建”进入甲片画布。在画布内导入图片或添加装饰，可拖动位置、双指缩放旋转，也可用缩放条和旋转按钮微调。“锁定位置”只固定中心位置，缩放与旋转仍然可用。底色支持预置色、6 位十六进制色号及透明；图片、装饰和手绘均按图层列表叠放，越靠上遮挡越靠前。橡皮只擦除其下方的笔迹，不会擦掉底色、图片或素材。撤销、重做可恢复图层顺序和笔迹。

素材库共 **82 个素材**，分为蝴蝶昆虫、花卉枝叶、星月闪光、爱心丝带、纹理叠层和海洋甜趣六类。本版新增六角冰晶、雪梅疏枝、青花缠枝和裂面金箔等 10 个可单独组合的素材。素材预览和导出均使用本地 Canvas 绘制的路径、渐变和纹理。

保存后可从“我的DIY”立即试戴，再次打开设计继续编辑。保存包含：

- `512×768` 的整矩形设计 PNG，保留底色及透明度。甲片轮廓只用于画布预览，PNG 不再次裁成椭圆；试戴时由照片的实际甲面蒙版裁切，避免二次裁切造成漏边。
- 可编辑 JSON 文档及应用自有图片副本。文档以相对路径引用图片，重新读取时按当前应用文档目录解析，支持应用容器路径变化。
- 每次修改独立的修订目录和 PNG 路径，避免命中旧图片缓存；旧修订暂时保留，供仍在试戴或撤销记录中的款式引用。

默认保存在应用文档目录 `DiyNails/`。索引在纹理和文档写完后原子替换，保存失败会保留当前已存版本；取消只清理草稿。删除仅允许自建条目，并删除它的私有修订与素材副本，不删除相册或文件中的原始图片。已经导出的效果图也会保留。卸载应用通常会清除这些本地设计，重要结果应另外导出保存。

## 甲面边缘与补选贴合（v0.6）

自动识别仍使用原有概率阈值和候选过滤。接受候选后才对其局部蒙版做内部满覆盖、填小洞、少量外扩及边缘羽化；这不会凭空新增识别数量，也不能恢复被模型漏掉的整片甲面。用户可按照片实际边缘再收缩或扩张蒙版，避免统一扩大后覆盖到皮肤。

v0.6.2 使用 3×3 闭合补小缺口，并与原有覆盖取并集，避免腐蚀步骤削掉尖角或贴边角点；填洞后以距离场生成默认 `0.65` 像素补边和 `0.35` 像素窄过渡。这里只作用于已接受的单片甲面蒙版，不修改识别概率和候选数量。宽度均为局部蒙版像素，实际照片中的过渡还受缩放与取样影响。

“重新贴合”在当前中心进行局部识别，再把新蒙版从照片坐标映射到用户设定的旋转坐标中；保留角度和中心，不能直接用自动估计的矩形替换用户结果。可靠新轮廓超框时扩大尺寸以容纳覆盖，识别回退时保留原轮廓。该操作可撤销。

手动补选的局部推理只接受包含点击种子的候选；若没有这样的候选，显示可编辑的手动轮廓。八点修边可直接调整甲尖、侧边和甲根，局部放大辅助看清边缘，扩缩与羽化控制覆盖范围及过渡。微调是在已有照片上估计边界，不保证自动精确拟合所有裸甲、反光、遮挡和斜拍场景。

自定义图片按蒙版逐行的可见宽度调整取样坐标，结合照片原有明暗、光泽及透明度融合，减少不规则甲面上的矩形贴纸感。这仍是 **二维形变与光照近似**，没有重建真实三维甲面，也不是经过校准的品牌色卡；不能改变甲长、修复遮挡或保证实际涂甲后的颜色一致。

## 预览识别链路（v0.4）

```text
相机预览流（iOS BGRA / Android YUV420）
→ 保留行步长、像素步长和方向信息，送入 Dart isolate
→ 转正、采样为 128×128 RGB，归一化为 float32 NCHW [-1,1]
→ 与照片共用同一 ONNX 模型，分别运行 0° / 180° 推理
→ 方向还原、连通域过滤和概率融合
→ 按预览的 cover 裁切映射甲面位置
→ 标记并统计中心位于当前视窗内的甲面
```

预览帧只在内存中处理，不编码为临时图片，也不写入磁盘。模型预热和推理按需进行；每次处理启动间隔至少 400 毫秒，已有帧在处理时直接丢弃新帧，不排队。这个间隔是节流设置，**不代表稳定帧率**，实际更新速度取决于手机和处理耗时。

结果以该帧进入处理时为起点，满 1.8 秒后清除；晚于有效期完成的结果也不会显示。等待中、未识别到和预览不可用分别显示状态，计数不会自动补成五个。预览使用矩形视窗内的甲面中心筛选，与标记绘制共用缩放及裁切坐标。

相机保留 `ResolutionPreset.high` 预设以维持拍照质量。持续取流在低端设备上可能影响流畅度、耗电和温度，需用真机 profile/release 构建评估。预览反馈有处理延迟；按快门时停止取流，再对保存的照片完整识别。两次输入的清晰度、时刻和采样方式不同，最终结果以照片编辑页为准。

## 照片识别链路与蒙版整理

```text
读取照片，修正 EXIF 方向
→ 工作图片最长边不超过 1600 像素
→ 可选手部定位（Android MediaPipe / iOS Vision，最多两只手）
→ 整图缩放为 128×128 RGB，生成 0° 与 180° 两个方向的输入
→ 每个方向运行同一 ONNX 指甲模型
→ 概率图恢复到统一方向，分别进行连通域过滤
→ 逐像素取 max 融合
→ 对融合结果再次应用相同过滤规则
→ 最多保留 12 处候选，生成局部蒙版和方向
→ 已接受候选的蒙版内部满覆盖、填洞、细补边和羽化
→ 照片专用：逐片局部模型复查、保守边界带融合、亚像素轮廓与抗锯齿
→ Flutter 片元着色器试戴
```

模型输入固定为 float32 `[1,3,128,128]`、RGB、NCHW，使用 `image` 包的 `Interpolation.average` 缩放整图，不做 letterbox，归一化为 `channel / 127.5 - 1`。输出为已经含 sigmoid 的 `[1,1,128,128]` 概率图，不应重复执行 sigmoid，也不应直接改成 256 输入。

每个方向和最终融合结果采用相同的正常筛选口径：

| 条件 | 当前值 |
| --- | --- |
| 前景概率阈值 | 0.38 |
| 连通域平均概率下限 | 0.57 |
| 最小连通域面积 | 3 个模型像素 |
| 最大连通域面积 | 整张概率图的 8% |
| 最多输出候选 | 12 处 |

过滤发生在融合前后两处，目的是让某一方向已被拒绝的大块背景不因 max 融合重新进入结果。阈值属于本 Demo 的实验取舍，并非可靠性或商业准确率保证；放宽小区域筛选也可能带来更多需要删除的误检。

v0.6.4 的照片精修不修改上述整图定位和预览筛选。已知甲面的局部裁剪允许较大前景占比（最多 65%），候选仍用 `0.38` 概率与 `0.57` 平均概率验证；与原甲面 IoU 至少 `0.65`、面积比 `0.7–1.35`、中心漂移不超过 `0.2√原面积` 才接受。融合局部与原始全图概率的权重为 `0.65/0.35`，修改范围限制在原边界附近，最终轮廓等值阈值为 `0.30`。这一阈值仅用于已验证且受边界带限制的绘制轮廓，不用于放宽全图检测。精细概率场按局部模型真实网格采样，最终 `128×192` 是绘制分辨率，不能凭空恢复模型没有提供的细节。

手部定位最多提供两只手的关节点，只用于尝试分配手指名称和甲面方向。找不到完整手、骨架与候选距离较远或同一手指已经匹配时，仍保留分割候选，以“甲面 N”编号和区域主轴方向呈现，不再要求用户改变为特定手型。

该模型是全图语义分割，不直接给出精确甲根/甲尖或三维甲面。渲染使用局部蒙版和简化光泽近似；旧甲油、反光、遮挡和小甲面仍需要确认、微调、补选或重拍。

## 实验结果与边界

v0.2 在 9 张上游照片的同组实验口径中，平均 Dice 从约 **0.570 提升到 0.690**，覆盖召回从约 **0.578 提升到 0.711**。这些材料来自上游示例或训练材料，**不是独立用户测试集**；数值不等于“所有指甲识别成功率”，也不能据此宣称自然拍摄问题已经解决。v0.4–v0.6 均未替换模型，这组历史结果不能代替预览、修边或局部补选的独立评测。

模型预处理另有一致性验证：Dart 的面积平均缩放是对上游 PIL bilinear 抗锯齿下采样的近似，不是逐像素相同。旧预处理比较中，average 比 Dart linear 更接近 PIL 基线；它衡量的是实现一致性，不是独立识别准确率。详情保留在 `assets/models/model_manifest.json` 和 `third_party/nail_model/PREPROCESS_VALIDATION.json`。

模型与来源说明：

- 模型来源：[nngeek195/nail-segmentation-v1](https://huggingface.co/nngeek195/nail-segmentation-v1)，上游模型卡声明 MIT，数据声明原文保留在 `third_party/nail_model/`。
- `assets/samples/hand.jpg` 来自上游 `nail_test_001636.jpg`，目前只保留为测试资源，**首页没有样本预览或示例入口**。
- Android 的手部模型与许可保留在 `assets/models/`；iOS 使用系统 Vision，不引入 MediaPipe iOS Pod，以避免与 ONNX 静态推理依赖冲突。
- Logo 使用用户提供的附件，保存在 `assets/branding/logo.jpg`，未通过生成式工具重新绘制。
